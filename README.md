## About The Project

**VJ NeuroX** is an AI-powered Natural Language Processing (NLP) web application designed to simplify text analysis and automate language-related tasks.

The platform brings multiple NLP tools together in one place, allowing users to analyze sentiment, identify named entities, detect abusive language, summarize content, translate languages, and perform various other text-processing operations.

Built using Python, Flask, Machine Learning, and Groq AI, the application provides an interactive interface for exploring real-world NLP applications.

## Live Application

**Try it here:** https://nlpwebapp.vercel.app/

## Key Features

### 1. Text Analysis & Understanding
- **Sentiment Analysis:** Identifies positive, negative, and neutral sentiments.
- **Named Entity Recognition (NER):** Extracts names, organizations, locations, and other entities.
- **Abusive Language Detection:** Identifies potentially abusive or inappropriate content.
- **Keyword Extraction:** Extracts important keywords from text.

### 2. Text Processing
- **Text Summarization:** Generates concise summaries from lengthy text.
- **Grammar Correction:** Helps identify and correct grammatical errors.
- **Language Detection:** Identifies the language of the given text.
- **Language Translation:** Translates text across multiple languages.
- **Spam Detection:** Classifies text messages as spam or legitimate.

### 3. AI-Powered Assistant
- Interactive AI assistant for text-related queries.
- Groq AI integration for AI-powered responses.

### 4. User Management
- User registration and login.
- User authentication.
- Personalized user profiles.

4. The backend processes the input using the relevant NLP functionality or AI integration.

## Installation & Setup

Follow these steps to run the project locally.

### Prerequisites

- Python 3.10+
- Git
- Groq API Key

### Step 1: Clone the Repository

```bash
git clone https://github.com/VASUJAIN2004/nlp_web_app.git
```

### Step 2: Navigate to the Project Directory

```bash
cd nlp_web_app
```

### Step 3: Create a Virtual Environment

```bash
python -m venv venv
```

### Step 4: Activate Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### Step 5: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 6: Configure Environment Variables

Create a `.env` file in the project root directory.

```env
GROQ_API_KEY=your_groq_api_key
```

Get your API key from: https://console.groq.com/

Never upload your API key or `.env` file to GitHub.

### Step 7: Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```

*Note: Use the actual Flask entry-point filename if your project uses a different one.*
